# KINGMAKER — MUNDANE ITEMS & QUALITY-OF-LIFE GEAR
## KM_Items_Mundane.md | Tools, Containers, Food, Clothing, Light, Packs

> **DM:** Load when the player shops for mundane gear, packs a kit at character
> creation (Option B/C in KM_BuildGuide.md), buys at Oleg's / Capital Market /
> Tannery / any general store. Covers what Owlcat-style RPG inventories take
> for granted — the stuff that isn't in the weapon/armor/consumable files but
> that the player might actually want to carry.
>
> All items here are **nonmagical**. Magical versions of many of these exist in
> KM_Items_Wilderness.md (enchanted quivers, folding boats, etc.) — this file
> is the baseline.
>
> **Related:** KM_BuildGuide.md · KM_Loot.md (tool tiers) · KM_Loot.md · KM_Items_Wilderness.md

## 🎒 PRESET ADVENTURING PACKS

> One-purchase bundles. Cheaper than buying components piecemeal. Shown as
> single inventory line item with a Bulk total. Intended for starting gear
> (KM_BuildGuide.md Option C) and restocking between chapters.
>
> **Pack Bulk:** Each pack's total weight is listed. Player may unpack and use
> each component individually after purchase.

### [P1] ADVENTURER'S PACK — 7 gp, 2 Bulk
```
 Backpack (large)        Bedroll              Chalk ×10
 Flint & Steel           Rope 50 ft (hemp)    Rations (1 week)
 Torch ×5                Waterskin
```
**Good for:** Any character. Baseline exploration kit. Already in [KM_BuildGuide.md](KM_BuildGuide.md).

### [P2] SCHOLAR'S PACK — 12 gp, 1 Bulk
```
 Backpack                Bedroll              Rations (1 week)
 Writing Kit             Parchment ×10        Scroll Case (hardened)
 Ink vial ×2             Magnifying Glass     Journal (blank)
```
**Good for:** Wizard, Witch, Investigator, Bard (scholar types), Psychic. Enables note-taking, Society/Lore checks, spell research.

### [P3] ENTERTAINER'S PACK — 9 gp, 1 Bulk

**Good for:** Bard, Swashbuckler, Rogue (charlatan builds). Performance + disguise + stage presence.

### Crafting Time & Cost

```
Base time : 4 days (minimum, regardless of item level)
Cost      : Half the item's listed price in raw materials
Each day  : Earn Progress = Crafting check result × item level ÷ 10 gp
When Progress ≥ remaining cost : Item complete
Critical success on initial check : Double daily progress
Critical failure : Day wasted; materials not consumed; try again
```

### Crafting Progress — Save Block

In-progress crafting projects must be recorded in the save block so they survive session transitions. Add to the player's save block under `"crafting_queue"`:

```json
"crafting_queue": [
  {
    "item_name": "Flaming Rune",
    "item_level": 8,
    "item_value_gp": 500,
    "materials_paid_gp": 250,
    "progress_gp": 180,
    "progress_remaining_gp": 70,
    "days_spent": 6,
    "daily_progress_gp": 30,
    "started_ingame_date": "14 Arodus 4710 AR",
    "status": "in_progress",
    "notes": "Critical success on Day 1 — doubled progress that day"
  }
]
```

**Fields:**
- `item_value_gp` — full listed price of the item
- `materials_paid_gp` — half of item_value_gp, paid upfront
- `progress_gp` — total progress earned so far (sum of daily check results)
- `progress_remaining_gp` — materials_paid_gp minus progress_gp (reaches 0 when done)
- `daily_progress_gp` — typical daily progress (last check result × level ÷ 10)
- `status` — `"in_progress"` / `"complete"` / `"failed"` / `"paused"`

**DM:** Update `progress_gp` and `days_spent` after each crafting day. When `progress_remaining_gp` reaches 0, set `status: "complete"` and add item to inventory. If player is away from their tools for 3+ days, set `status: "paused"` — progress is preserved but no new progress accrues.

## 🪤 HOW TRAPS WORK (Quick Reference)

```
┌──────────────────────────────────────────────────────────┐
│ 4 STATS DEFINE EVERY TRAP:                                │
│   1. Stealth DC  — Perception check to notice unsprung    │
│   2. Disable DC  — Thievery (mundane) or Arcana (magical) │
│   3. Trigger     — what sets it off (step, weight, touch) │
│   4. Effect      — damage/condition; save DC & type       │
└──────────────────────────────────────────────────────────┘

DETECTION:
 · Passive Perception (walking through) vs Stealth DC = pass by safely
 · Active Search (1 min) grants +2 circ. to Perception
 · Trap-Spotter's Candle / Detect Anathema Censer / Detect Magic reveal
   within their range; see KM_Items_Expanded.md § Detection

DISABLE:
 · Thievery (mechanical traps)
 · Arcana / Occultism / Nature (magical traps — match tradition)
 · Crafting (complex mechanisms)
 · Critical success = disabled, reusable (if salvageable)
 · Success = disabled
 · Failure = trap still armed
 · Critical failure = trap triggers immediately on you

DEPLOY (player-set trap):
 · Crafting check (Snare) OR Thievery (mechanical) OR spell (magical)
 · Uses trap components from this file
 · Deploy time: 1 min basic, 10 min complex, 1 hour elaborate
 · Limited uses per day: (trained 4) / (expert 6) / (master 8) / (legendary 10)

SALVAGE:
 · Critical success on Disable → recover 50% component cost (round down)
 · Magical traps never salvaged (spell is expended)
```

## 📋 DM NOTES

**Trap placement by chapter:**
- **Pre-Prologue / Prologue:** no mechanical traps (social tone); Malak's parchment is a "trap" in a narrative sense only
- **Ch1 Stolen Lands:** L1–3 traps in bandit camps (Kressle, Stag Lord fort); simple pits, dart traps, tripwire alarms
- **Ch2 Troll/Bloom:** L3–5 traps in troll caves; magical Bloom traps start appearing in fey-blighted hexes
- **Ch3 Varnhold:** L5–7 traps in Vordakai's tomb; ancient cyclopean mechanical + necromantic sigils
- **Ch4–5 Pitax/Armag:** L7–9 traps in palace + tomb; Irovetti's paranoid security (mundane heavy)
- **Ch6 Thousandbreaths:** L9–13 fey traps; Nyrissa's riddles encoded as ward sigils
- **Ch7 Finale:** L13+ soul-binding traps around Nyrissa's heart tree

**Player-deployable snares / mechanical traps as ROGUE/RANGER REWARD:**
- Ranger (Build 3, Sniper & Flurry variants): Snare Crafter at L4
- Alchemist: Can prep alchemical snares instead of bombs
- Rogue: Trap Finder feat (L1) reduces Stealth DC by 2 to find traps; Mechanical Expertise (L9) lets them set mechanical traps in half the time
- Rogue Thief: Treat Disarm as Master at L7

**Salvage rules:**
- Mechanical traps: 50% material cost recovered on crit success Disable
- Magical traps: cannot be salvaged; spell is expended regardless of outcome
- Snares: single-use; cannot recover unless feat explicitly allows (Stealthy Sniper feat, some Alchemist discoveries)

**Loot placement (found traps):**
- Bandit fort boss rooms: 2–3 minor traps at Ch1 tier
