# KINGMAKER — PF2e ACTION REFERENCE
## KM_Actions.md | Referenced by: KM.txt

---

## 🎯 PURPOSE OF THIS FILE

This file exists for **one reason**: to give the DM a source of actions to fill choice menus without resorting to story hints, spoilers, or invented content.

**The DM pulls from this list when building the 10–30 option choice menu required by the Player Agency rules in KM.txt.**

---

## ⚠️ ANTI-SPOILER RULE — READ FIRST

> **Full anti-spoiler rule with examples, the disclaimer loophole, softened phrasing ban, and the complete 3-question test: see `KM_DMRules.md`.**

**Core rule:** Never add a choice menu option that implies knowledge the player does not currently have. If an option only exists because the DM knows something is coming, remove it. Do not rephrase it — remove it.

**The test:** Would a player with no plot knowledge plausibly think of this option on their own, based only on what they currently know and observe? If no — remove it.

---

## 📖 HOW THE DM USES THIS FILE

**Step 1 — Identify the current mode.**
Is the player in Encounter (combat/initiative), Exploration (moving/investigating), Social (conversation/negotiation), Camping, Downtime, or Kingdom mode?

**Step 2 — Build the base menu from the scene.**
Start with choices that come directly from the scene: NPCs present, objects visible, ongoing situations, the player's current goal.

**Step 3 — Check the player's build.**
Pull their trained/expert/master/legendary skills from the character sheet. Their class abilities. Their spells. Their equipment. Add options that use what they actually have.

**Step 4 — Fill remaining slots from this list.**
If the menu is under 10 choices, pull from the relevant mode section below. Filter by: Does this make sense in the current situation? Would the character plausibly think of this without knowing the plot? If yes, add it. If no, skip it.

**Step 5 — Always include Custom Action as the last option.**
The player can always do something not on the list.

**Step 6 — COMBAT ONLY: Always append consumables and activatable items.**
In Encounter mode, after all tactical options, append a `💊 CONSUMABLES & ⚡ ITEM ABILITIES` section to every combat choice menu. Pull from the player's current inventory. Only show items where the use condition is relevant right now — do not list everything blindly. See rules below.

### 💊 CONSUMABLES & ⚡ ITEM ABILITIES — COMBAT MENU APPENDIX

> **DM:** This section is MANDATORY at the bottom of every combat choice menu. Always appears after the regular tactical options. Pull from the player's inventory in the save block. Apply the relevance filter — only show items where the situation makes them useful right now. If the player has no relevant items, show the section header with "None currently applicable."

**Relevance filter — show a consumable if ANY of these are true:**
- Player or an ally is at ≤ 50% HP → show healing potions / elixirs
- Player or an ally has an active condition the item counters → show relevant remedy (Antitoxin for poison, etc.)
- An enemy is grouped with others within 10 ft → show splash weapons / bombs
- An enemy has a damage type vulnerability the item exploits → show relevant oil or weapon buff
- Combat is against a named boss or the encounter is flagged as severe/extreme → show all 1/day abilities
- A tactical advantage would be opened by using the item this round → show it

**Relevance filter — show an activatable equipment ability if ANY are true:**
- The ability's effect is better than a Strike against the current target
- Using it would open a status effect, condition, or positioning advantage not otherwise available
- It is not on cooldown and its frequency has not been used today (unless boss fight — then always show)

**Format — append at the bottom of every combat WHAT DO YOU DO? menu:**

```
──────────────────────────────────────────────
💊 CONSUMABLES  (1A to draw + activate unless noted)
──────────────────────────────────────────────
[##]. [Item Name] — [Effect] | [Why relevant now]
[##]. [Item Name] — [Effect] | [Why relevant now]
      (None currently applicable)  ← if filter returns nothing

──────────────────────────────────────────────
⚡ ITEM ABILITIES  (cost varies)
──────────────────────────────────────────────
[##]. [Item Name] — [Ability] | Cost: [X]A | [Why relevant now]
[##]. [Item Name] — [Ability] | Cost: [X]A | [Why relevant now]
      (None currently applicable)  ← if filter returns nothing
```

**Rules:**
- Numbering continues from the last regular combat option (e.g., if options end at 09, consumables start at 10).
- Each entry gets one short "why relevant now" note — not a stat block, just the tactical reason.
- If the player has an item in inventory but it fails the relevance filter, do NOT show it. Do not pad this section.
- Draw + Activate costs 1A for most consumables (Interact to draw, then Activate). Note if an item is already drawn/accessible.
- 1/day and frequency-limited abilities show their remaining uses: `[1/day — unused]` or `[1/day — spent]`.
- Omit this appendix entirely only if the player has zero consumables and zero activatable item abilities in inventory.

> **HOST GATHERING (D14):** *Requires Inn, Festival Hall, or better. Once per chapter.*
> Cost: 20 gp × level (Linzi or Octavia Friendly+ assists: −10 gp × level).
> Roll Diplomacy vs DC 14 + Unrest: Crit → Unrest −2, +3 companion rolls, log Bond Moment; Success → Unrest −1, Morale +2, +1 rolls; Failure → gold spent only; Crit Fail → Unrest +1, Reputation −1 local.
> DM runs 3 companion beats (player picks; one may be a named NPC guest). Up to 3 NPCs invited — attendees gain +1 attitude step; declines noted. Replaces Celebrate Holiday that turn; cannot stack.
> One moment per gathering (DM picks): Linzi asks the player one question for the record | Valerie guards the door | Amiri wins an arm-wrestle; Morale +1 regardless | Nok-Nok befriends the cook | Harrim gives one good piece of advice | Tristian finds whoever most needs to be seen.

## 🎭 SOCIAL INTERACTION — ATTITUDE TRACK

When the DM manages NPC attitudes, use this track:

```
HOSTILE → UNFRIENDLY → INDIFFERENT → FRIENDLY → HELPFUL

Hostile    : Will attack, obstruct, or actively harm
Unfriendly : Uncooperative; won't help; may oppose
Indifferent: Neutral; will deal but won't go out of way
Friendly   : Cooperative; will assist with simple requests
Helpful    : Actively aids; will take risks to help

Make an Impression: improves attitude one step (Diplomacy check)
Coerce            : forces compliance but drops to Unfriendly after
Request           : requires Friendly or Helpful to succeed
```

## ⚔️ TACTICAL COMBAT RULES

### Flanking
```
Two creatures on OPPOSITE sides of an enemy (both threatening melee) = flanked.
Flanked enemy is OFF-GUARD (−2 AC) to both flankers. Enables Sneak Attack.
Mark on ASCII map with [F] tag.
```

### Cover
```
Lesser  (+1 AC/Ref) : Low obstacle, partial obstruction
Standard(+2 AC/Ref) : Solid obstacle, half body covered
Greater (+4 AC/Ref) : Only small gap visible
Take Cover action: 1A to gain standard cover if adjacent to obstacle.
```

### Splash Damage
```
Direct hit: Full damage. Adjacent creatures (5 ft): splash value.
Allies in splash radius ARE affected. Miss: lands in random adjacent square.
```

### Bonus Stacking
```
Status, Circumstance, Item bonuses: DO NOT stack (highest only).
Untyped bonuses and Penalties: ALWAYS stack.
Example: Bless (+1 Status) + Inspire Courage (+1 Status) = +1 total, not +2.
```
