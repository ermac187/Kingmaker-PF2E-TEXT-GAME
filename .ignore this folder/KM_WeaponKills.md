# REGULAR KILL SEQUENCES — THE SUB-FINISHER LAYER
## For ordinary killing blows that do NOT meet a finishing-move trigger. Applies to every attacker — eRmaC, companions, enemies, creatures.

> **DM:** This file is for the constant case — a normal hit that drops a standard enemy. It is the layer BELOW the finishers. Use it whenever a killing blow does **not** meet a finisher trigger, so a regular death is still concrete, weapon-correct, and lethal — never softened, never skipped, but never inflated into a setpiece either.

---

## WHEN THIS FILE FIRES (vs the finisher files)

A killing blow routes to a **FINISHER** (KM_GuisarmeFinishers / KM_CompanionFinishers / KM_WeaponFinishers) if ANY of these is true (KM_Combat_Systems.md § FINISHING MOVES):
- **Critical hit** that drops the enemy to 0
- **Overkill** ≥ 1% of the target's max HP (the Clean threshold)
- **Stage Fatality** (sent into an environmental hazard)
- **Boss / named** enemy kill

If **NONE** of those is true — a non-crit hit on a standard enemy that brings them to ~0 with no real overkill — it is a **REGULAR KILL** and routes **here**.

⛔ Do NOT promote a regular kill into a finisher tier (Clean/Brutal/Savage/Annihilation) when no trigger fired — inventing overkill to justify a fatality = `.fail 9`. ⛔ Do NOT demote a triggered finisher down to a regular kill to avoid the graphic content — if a trigger fired, the finisher file is mandatory.

---

## HOW TO USE

1. **Confirm no finisher trigger fired** (above). If one did, stop — use the finisher file.
2. **Match the attacker's weapon or damage type** to a section below.
3. **Pick the body location** the hit landed (chest / gut / throat / head / back). The DM chooses by where the strike connected; if position doesn't dictate it, default to **chest**.
4. **Pick the weight** by how the hit landed:
   - **GLANCING-LETHAL** — the blow caught a vital line but wasn't square. Death comes, but it takes a beat: a step, a stagger, a hand to the wound. Use for grazing hits, low-roll-but-lethal, the enemy already hurt.
   - **SOLID** — a square, committed hit. Drops on the spot, decisively. This is a clean lethal hit at ~0 overkill: NO separation, NO spectacle, NO room-decoration (that is finisher territory). One motion, down, finished.
5. **One sentence.** Regular kills are SHORT — they keep combat moving. Write the line (verbatim or in close substance), then continue the turn. No tier label. No morale bump (that is finishers only).

eRmaC's **guisarme** uses the **HALBERD / POLEARM / GUISARME** section here for regular kills. **Companions** use their matching weapon/damage section here for regular kills — bespoke companion text is for finishers only.

Softening a regular kill into "he falls / she collapses" with no wound = `.fail 9`. Skipping the kill description = `.fail 9`.
