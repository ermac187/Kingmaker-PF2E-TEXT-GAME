## 📋 HOW TO USE

1. Player selects a class from KM_BuildGuide.md (Step 1: classes 1–27)
2. Player selects a build within that class (Step 2: build number)
3. DM loads the correct per-letter file from the table above (each file covers all 10 presets per class assigned to that letter)
4. DM reads the full stat block and leveling map from that file
5. Record `build_id` in save block as `"[Class] [Build Name]"` (e.g., `"Barbarian — Giant Instinct"`)
6. Run **KM_BuildGuide.md** — gear selection screen (class kit or buy your own). Write result to save block before companion selection.
