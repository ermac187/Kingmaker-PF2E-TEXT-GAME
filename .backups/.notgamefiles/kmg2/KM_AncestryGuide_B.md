## [15] KINETICIST — Primary: CON · Secondary: varies by element

**Role:** Sustained elemental blaster, no daily limits. CON is your entire DC — impulses, saves, HP, kinetic aura range. Secondary varies: WIS (wood/water for reach), STR (metal/earth for melee), DEX (air for mobility).
**Poor picks cost:** Halfling (CON focus works but no element-specific heritage). Goblin (−WIS flaw + no CON primary heritage default for most elements). On Kineticist the wrong ancestry = your impulse DC is 2–3 behind the curve = enemies save on 11+ instead of 14+.

```
★ Dwarf       — +CON+WIS/STR, Crimson Shroud or Stone heritage = element fit
 2 Goliath    — +STR+CON, Large for Jotunborn size impulse (build 9)
 3 Human      — Natural Ambition = gateway feat at L1
 4 Leshy      — +CON+WIS, Wood Kineticist natural fit, Seedpod synergy
 5 Gnome      — +CON+CHA, Umbral for shadow, Vivacious for mobility
OK : Undine (Azarketi — water kineticist) · Efreeti-touched Fetchling · Orc (fire)
AVOID: Halfling (CON focus ok but no element-specific heritage)
BUILD EXCEPTIONS:
  - Jotunborn Size Impulse (9) → Goliath REQUIRED
  - Wood/Air Mobility (2) → Nimble Elf or Leshy (Seedling)
  - Fire/Earth builds (3) → Dwarf (Forge/Crimson/Stone) any of them
```

## [16] MAGUS — Primary: STR or DEX · Secondary: INT, CON

**Role:** Spellstrike burst — weapon Strike + spell in one action. STR for melee Twisting Tree / Inexorable Iron; DEX for Starlit Span ranged; INT for spell DC and slot count; CON for frontline tanking.
**Poor picks cost:** Halfling (STR ceiling low for melee Magus). Goblin (INT cap 16 = weak spell DC). Orc/Goliath INT cap is worst — you lose Spellstrike consistency AND attack accuracy simultaneously.

```
★ Human       — Natural Ambition = Spellstrike feat at L1
 2 Elf        — +DEX+INT, Ancient Elf is the Magus race, speed 30
 3 Half-elf   — Aiuvarin for Elf feats without losing CHA flex
 4 Orc        — +STR+CON, Ferocity for frontline Twisting Tree
 5 Dwarf      — +CON+STR, Anvil Dwarf for Inexorable Iron
OK : Hobgoblin (Remorseless Lash) · Gnome (flavor only, MAD pressure)
AVOID: Halfling (STR ceiling low for melee Magus), Goblin (INT cap)
BUILD EXCEPTIONS:
  - Starlit Span (2) → Nimble Elf or Ancient Elf for ranged finesse
  - Psychic Amp (4) → Ancient Elf REQUIRED
  - Inexorable Iron (1) → Dwarf or Orc for STR + CON pressure
```

## [17] MONK — Primary: STR or DEX · Secondary: WIS, CON

**Role:** Unarmored striker + stance mastery. STR for Mountain/Tiger unarmed punch/claw; DEX for Crane/Wolf finesse + unarmored AC; WIS adds to unarmored AC (class feature) and Ki focus DC; CON for HP.
**Poor picks cost:** Gnome / Leshy (STR ceiling low for unarmed scaling). Hobgoblin (no WIS heritage default — monk's triple-stat math breaks). Goliath fine for STR builds but DEX builds suffer.

```
★ Human       — Natural Ambition = stance feat at L1
 2 Elf        — +DEX+INT, Nimble Elf for +5 speed, Ancient Elf for dip
 3 Orc        — +STR+CON, Ferocity for Pure Flurry frontline
 4 Dwarf      — +CON+STR, Mountain Monk synergy, Stonewalker
 5 Halfling   — +DEX+WIS, Keen Eyes, Halfling Luck
OK : Tengu (ancestral warrior flavor) · Hobgoblin (Ki discipline) · Catfolk (mobility)
AVOID: Gnome, Leshy (STR ceiling clashes with unarmed scaling)
BUILD EXCEPTIONS:
  - Jotunborn Giant Stance (9) → Goliath or Orc REQUIRED
  - Monastic Archer (10) → Elf (Ancient) or Halfling (Keen Eyes)
  - Crane/Wolf Stance (4) → Nimble Elf or Halfling for mobility
```

## [18] ORACLE — Primary: CHA · Secondary: varies by mystery

**Role:** Cursed divine caster. CHA sets spell DC + curse scaling + Revelation spells. Secondary varies: Battle/Warrior = STR; Bones/Life = CON or WIS; Flames = CON; Cosmos = DEX.
**Poor picks cost:** Goblin (CHA works but clashes with Will-save pressure from curse escalation — you'll enter Extreme Curse faster than intended). Orc/Goliath (CHA cap low, curse bleeds faster).

```
★ Human       — Natural Ambition = mystery feat at L1, Aasimar/Nephilim flavor
 2 Dwarf      — +CON+WIS (Bones/Battle), Clan Dagger
 3 Halfling   — +DEX+WIS+CHA heritage, Luck reroll vs curse
 4 Half-elf   — +CHA flex, Aiuvarin for flavor heritage
 5 Orc        — +STR+CON for Battle/Warrior Mystery frontline
OK : Gnome (Cosmos flavor) · Nagaji (Ancestors Mystery) · Tiefling (any mystery)
AVOID: Goblin (CHA ok but clashes with WIS save pressure)
BUILD EXCEPTIONS:
  - Battle/Warrior Mystery (1, 8) → Orc/Dwarf/Human STR frontline
  - Life/Bones Mystery (2, 6) → Halfling/Gnome/Dwarf for fragile caster
  - Flames Mystery (3) → Human with Aasimar heritage for flavor
```

## [19] PSYCHIC — Primary: INT or CHA · Secondary: CON

**Role:** Amped-cantrip blaster. INT or CHA (pick one as Conscious Mind stat) sets spell DC + amp potency; CON for HP. DEX purely for AC.
**Poor picks cost:** Orc / Goliath (MAD pressure + low INT/CHA ceiling = your amp DC stays 2 behind the curve). Your amp cantrips whiff on bosses who should eat them.

```
★ Halfling    — +DEX+WIS+CHA heritage, Luck reroll for focus saves
 2 Human      — Natural Ambition = amp feat at L1
 3 Elf        — +DEX+INT, Ancient Elf for dual tradition dip
 4 Gnome      — +CON+CHA, First World Magic stacks with Psychic
 5 Goloma     — +WIS+CON, Panicked Mind ancestry flavor (rare)
OK : Fetchling (shadow flavor) · Tengu (ancestral memory) · Vanara (prehensile)
AVOID: Orc, Goliath (MAD, INT/CHA ceiling)
BUILD EXCEPTIONS:
  - Mindsmith + Magus (9) → Ancient Elf REQUIRED
  - TK Projectile + Fighter (4) → Human or Halfling for DEX precision
```

## [20] RANGER — Primary: DEX or STR · Secondary: WIS, CON

**Role:** Hunt-Prey precision striker + pet handler. DEX for archer/finesse-flurry; STR for melee-flurry; WIS for Perception, Nature, Survival + primal spells on Warden builds; CON for HP.
**Poor picks cost:** Gnome / Goblin (no Ranger-stat synergy heritage — you lose both primary boost AND secondary feat synergy). Halfling is fine despite STR cap if going DEX archer.

```
★ Elf         — +DEX+INT, speed 30, Nimble Elf for extra +5 in Ranger Field Stride
 2 Halfling   — +DEX+WIS, Keen Eyes, Luck reroll for Hunt Prey precision
 3 Human      — Natural Ambition = Hunt Prey feat at L1
 4 Half-elf   — Aiuvarin — +WIS/DEX flex, Elf feats via heritage
 5 Orc        — +STR+CON, Ferocity for melee Flurry Hunter
OK : Tengu (ancestry flavor) · Catfolk (mobility) · Leshy (Wood Ranger)
AVOID: Gnome, Goblin (no Ranger-stat synergy heritage)
BUILD EXCEPTIONS:
  - Archer Sniper (3) → Elf (Ancient) or Halfling for range precision
  - Companion Pure (8) → Halfling (Mount heritage) or Leshy (Seedling bond)
  - Flurry Hunter (1, 5) → Human or Half-elf for 2 weapon Ancestry feats
```

## [21] ROGUE — Primary: DEX · Secondary: CHA, INT, WIS

**Role:** Sneak-attack specialist + skill monkey. DEX drives attack, AC, Reflex, stealth. Secondary depends on racket: CHA (Scoundrel), INT (Mastermind), STR (Ruffian).
**Poor picks cost:** Orc / Goliath (DEX ceiling clashes with Sneak Attack accuracy — the class only deals damage on hits, and you miss more). Ruffian STR racket is the ONLY exception — those SHOULD pick Orc/Goliath.

```
★ Halfling    — +DEX+WIS, Keen Eyes, Halfling Luck, Hidden Mouser
 2 Elf        — +DEX+INT, Nimble Elf for +5 speed Thief racket
 3 Human      — Natural Ambition = sneak feat at L1
 4 Goblin     — +DEX+CHA, Razortooth for Ruffian bite-attack
 5 Tengu      — +DEX+WIS, Tengu Lore for scoundrel skill monkey
OK : Catfolk (Land on Feet) · Ratfolk (Cheek Pouches) · Gnome (Pyromaniac)
AVOID: Orc, Goliath (DEX ceiling clashes with Sneak Attack)
BUILD EXCEPTIONS:
  - Ruffian + Magus (2) → Orc or Goliath (only STR-based Rogue)
  - Eldritch Trickster (4) → Ancient Elf REQUIRED
  - Thief Dexterity God (6) → Nimble Elf REQUIRED for +5 speed
  - Shadowdancer Stealth (9) → Elf or Fetchling for light manipulation
```

## [22] SORCERER — Primary: CHA · Secondary: CON

**Role:** Spontaneous bloodline caster. CHA sets spell DC, attack, and known-spell count; CON for HP (spellcasters are squishy).
**Poor picks cost:** Orc / Goliath (MAD pressure, CHA ceiling — your spell DC caps at 16 instead of 18, enemies save 20%+ more often). The difference between CHA 18 and CHA 16 on Sorcerer is roughly 10% of your total damage over a campaign.

```
★ Human       — Natural Ambition = bloodline feat at L1, Aasimar/Tiefling heritage
 2 Half-elf   — Aiuvarin — +CHA flex, Elf feats for speed
 3 Gnome      — +CON+CHA, First World Magic stacks, Fey Gnome heritage
 4 Halfling   — +DEX+WIS+CHA heritage, Luck reroll for spell save
 5 Tiefling-touched (any ancestry) — Divine/Infernal bloodline flavor
OK : Dhampir-touched · Dwarf (CON tank) · Elf (Nimble for mobility)
AVOID: Orc, Goliath (MAD pressure, CHA ceiling)
BUILD EXCEPTIONS:
  - Draconic Blaster (1) → Human/Kobold (Dragonscale heritage)
  - Wild Magic (9) → Gnome (chaos-aligned heritage fit)
  - Shadow Control (4) → Fetchling REQUIRED (or Umbral Gnome)
```

## [23] SUMMONER — Primary: CHA · Secondary: CON (link-HP)

**Role:** Eidolon-partner caster — you share actions + HP with your eidolon. CHA sets eidolon's attacks and your spell DC; CON matters DOUBLE (you and eidolon share an HP pool via Link).
**Poor picks cost:** Orc / Goliath (MAD + CHA ceiling — eidolon attacks miss AND link economy caps low). The eidolon's stats are directly derived from yours, so every stat penalty doubles.

```
★ Human       — Natural Ambition = eidolon evolution feat at L1
 2 Gnome      — +CON+CHA, Fey Gnome for fey eidolon flavor
 3 Halfling   — +DEX+WIS+CHA heritage, Luck reroll for Tandem Strike
 4 Leshy      — +CON+WIS, Plant Eidolon natural fit
 5 Tengu      — +DEX+WIS, ancestral guide eidolon flavor
OK : Tiefling-touched (fiend eidolon) · Aasimar-touched (angel eidolon)
AVOID: Orc, Goliath (MAD — CHA ceiling for link economy)
BUILD EXCEPTIONS:
  - Martial Eidolon + Magus (1) → Human or Ancient Elf
  - Plant Tank + Guardian (2) → Leshy REQUIRED for flavor synergy
  - Dragon Eidolon Blaster (4) → Kobold (Dragonscale) or Human
```

## [24] SWASHBUCKLER — Primary: DEX · Secondary: CHA, CON

**Role:** Panache-powered precision striker + mobility. DEX drives attacks, AC, stylish maneuvers; CHA drives Bon Mot, Tumble-through, Precise Strike damage scaling; CON for frontline.
**Poor picks cost:** Orc / Goliath (DEX ceiling clashes with Panache generation — you miss tumble/trip rolls and lose Panache). This cascades: no Panache = no Finisher = 50% of your damage disappears.

```
★ Halfling    — +DEX+WIS+CHA heritage, Luck reroll, Hidden Mouser
 2 Human      — Natural Ambition = panache feat at L1
 3 Half-elf   — Aiuvarin for Elf feats + CHA flex
 4 Catfolk    — +DEX+CHA, Land on Feet, Cat's Luck reroll
 5 Tengu      — +DEX+WIS, flavor for duelist
OK : Elf (Nimble for mobility) · Gnome (bon mot flavor) · Vanara (acrobatic)
AVOID: Orc, Goliath (DEX ceiling clashes with Panache)
BUILD EXCEPTIONS:
  - Gymnast Grapple + Monk (2) → Orc or Human for STR grapple
  - Pirate + Commander (8) → Half-elf or Human for CON banner bearer
  - Panache + Gunslinger (1) → Halfling or Human for dual-stat DEX+CHA
```

## [25] THAUMATURGE — Primary: CHA · Secondary: CON

**Role:** Implement-wielder + Exploit Vulnerability precision. CHA drives Exploit DCs, implement intensity, and Personal Antithesis; CON for frontline tanking multi-implement builds.
**Poor picks cost:** Orc / Goliath (CHA ceiling — Exploit Vulnerability saves miss and your force-multiplier role fails). Small ancestries (Gnome) work but struggle with two-handed weapon implement.

```
★ Human       — Natural Ambition = implement feat at L1, Aasimar/Tiefling flavor
 2 Half-elf   — +CHA flex, Aiuvarin for Elf feats
 3 Halfling   — +DEX+WIS+CHA heritage, Luck reroll, Keen Eyes
 4 Gnome      — +CON+CHA, First World Magic stacks with Exploit
 5 Tiefling-touched — Esoteric flavor, innate spell occult fit
OK : Dhampir-touched (undead hunter) · Fetchling (shadow implements) · Tengu
AVOID: Orc, Goliath (CHA ceiling)
BUILD EXCEPTIONS:
  - Weapon Implement + Fighter (2) → Human or Orc for STR weapon
  - Cursed Saboteur (3) → Human Versatile (L1 general feat = Reach Weapon)
  - Exemplar Ikon Dip (8) → Human for dual-resource flexibility
```

## [26] WITCH — Primary: INT · Secondary: CON, CHA

**Role:** Patron-bound caster + hex debuffer. INT sets spell DC + hex save DC; CON for HP; CHA for secondary social hexes (Lesson of Vengeance, etc.).
**Poor picks cost:** Orc / Goliath (INT ceiling = hex DC stays 2 behind boss Will saves). Goblin is flavor-only (−WIS hurts your Will saves and you need patron protection).

```
★ Gnome       — +CON+CHA, First World Magic stacks with Witch Patron
 2 Human      — Natural Ambition = hex feat at L1
 3 Halfling   — +DEX+WIS+CHA heritage, Luck reroll
 4 Leshy      — +CON+WIS, Wilding Patron natural fit, Seedpod familiar
 5 Elf        — +DEX+INT, Ancient Elf for Wizard dip
OK : Tengu · Ratfolk (familiar flavor) · Goblin (Razortooth)
AVOID: Orc, Goliath (INT ceiling)
BUILD EXCEPTIONS:
  - Hexblaster + Magus (2) → Ancient Elf or Human
  - Patron Spell + Wizard (3) → Ancient Elf REQUIRED
  - Beastbound Familiar + Druid (6) → Halfling (Mount) or Leshy
```

## [27] WIZARD — Primary: INT · Secondary: CON

**Role:** Prepared arcane caster + spell-versatility king. INT sets spell DC, spells-per-day, and spell attack; CON for HP (wizards have d6 — you need the buffer).
**Poor picks cost:** Orc / Goliath (INT ceiling). Goblin (no INT heritage default). On Wizard the primary-stat penalty compounds worst of any caster — you get fewer slots AND weaker DC AND less spellbook expansion over 20 levels.

```
★ Elf         — +DEX+INT, Ancient Elf is the Wizard race, speed 30
 2 Human      — Natural Ambition = metamagic feat at L1
 3 Gnome      — +CON+CHA, First World Magic stacks with Arcane
 4 Halfling   — +DEX+WIS+CHA heritage, Luck reroll for save
 5 Tengu      — +DEX+WIS, Tengu Lore for skill-god utility Wizard
OK : Ratfolk (tinker wizard) · Kobold (Dragonscale) · Aasimar/Tiefling (any ancestry)
AVOID: Orc, Goliath (INT ceiling), Goblin (no INT heritage default)
BUILD EXCEPTIONS:
  - School Specialist + Magus (2) → Human or Ancient Elf
  - Staff Specialist + Cleric (6) → Dwarf (WIS+INT balance)
  - Battle Magic + Fighter (8) → Orc or Human for STR frontline
  - Exemplar Transcendence (9) → Human REQUIRED for dual-class flex
```

## 🧬 VERSATILE HERITAGES

> **⛔ Full per-ancestry heritage catalog + Versatile Heritage effects: `KM_Heritages.md`.** This file (AncestryGuide) is the class-fit recommendation layer. Heritages are free — they do not cost ancestry feat slots.

Versatile Heritages (any ancestry, free): **Nephilim (Celestial)** = formerly Aasimar, darkvision + resist void + innate Light. **Nephilim (Fiendish)** = formerly Tiefling, darkvision + resist fire + innate Produce Flame. **Changeling** = claws + hag lineage. **Dhampir** = darkvision + negative healing + charm resist. **Duskwalker** = damning strikes vs undead + ghost sight. **Beastkin** = animal aspect shift. **Aiuvarin** = formerly Half-Elf, low-light + elf feat access. **Dromaar** = formerly Half-Orc, low-light + Orc Ferocity.

**Rule:** Ancestry FIRST, heritage SECOND. Versatile heritage layers on top — does not change ancestry stat bonuses.

## 📋 DM DISPLAY PROCEDURE AT STEP 3

1. Look up class (sections [1]–[27] across `KM_AncestryGuide.md` and `KM_AncestryGuide_B.md`). 2. Copy Role + Poor-picks + ★/2-5/OK/AVOID + BUILD EXCEPTIONS verbatim. 3. Output "Your build works best with these ancestries:" + the block. 4. If BUILD EXCEPTION fires, say "⛔ This build REQUIRES [ancestry] for synergy." 5. Prompt "Pick an ancestry — ★ or any number, or type another." 6. Accept any legal PF2e ancestry; note trade-off for off-list. 7. Proceed to Step 4 Heritage (load `KM_Heritages.md`).

## 📋 DM NOTES

**Stat stacking:** ancestry + background + class KEY + free boosts = starting stats. Most = 2 specific + 1 free. Human = 2 free.
**Heritages are free** — never consume ancestry feat slots. Full catalog: `KM_Heritages.md`.
**Ancient Elf** grants a multiclass dedication feat at L1 ignoring level prereqs. Builds tagged "Ancient Elf REQUIRED" have NO substitute.
**Kingmaker setting:** all ancestries accepted. Brevoy culture favors Human / Half-orc / Dwarf as "common" — flavor reaction only, no mechanics. Exotic = scrutiny in noble courts, warmth in wilderness.
