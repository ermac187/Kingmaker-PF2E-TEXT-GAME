## 📋 HOW TO USE

1. Player selects a class from KM_BuildScreen.md (Step 1: classes 1–27)
2. Player selects a build within that class (Step 2: build number)
3. DM loads the correct file from the table above
4. DM reads the full stat block and leveling map from that file
5. Record `build_id` in save block as `"[Class] [Build Name]"` (e.g., `"Barbarian — Giant Instinct"`)
6. Run **KM_StartingGear.md** — gear selection screen (class kit or buy your own). Write result to save block before companion selection.
