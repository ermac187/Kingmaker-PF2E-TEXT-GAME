# KINGMAKER — SHADOWBANE ARMOR APPEARANCE TABLE
## KM_Armor_Appearance.md | Referenced by: KM_Exploration.md, KM_PrePrologue_Builds.md, KM_PrePrologue_Builds_B.md

> **DM:** Use this table for visual narration and NPC reactions when eRmaC's armor is visible. Race-locked entries only appear on builds for that race. **Aracoix** = bird-race of Aerynth; Golarion equivalents: Tengu, Strix, Garuda — NPCs may recognize the wing-accommodation cuts as bird-built without identifying the material. For full NPC reaction text, look up the Material name in the ⚗️ Exotic Materials table in `KM_Exploration.md`.

## 📋 RACE-LOCK RULES

**Armor labeled race-locked cannot be worn by other ancestries.** If a non-Aracoix build has Aracoix Scale assigned in `KM_PrePrologue_Builds_B.md`, that is the *material* (Aracoix Scale) fitted to a standard Scale Mail form — the wing-accommodation cuts are absent. Only builds with the Aracoix ancestry have the true race-locked fit.

| Race-Locked Armor | Aerynth Race | Golarion Equivalent |
|-------------------|-------------|---------------------|
| Aracoix Armor | Aracoix | Tengu / Strix / Garuda |
| Centaur Armor | Centaur | Nomen Centaur (non-PC) |
| Minotaur Armor | Minotaur | Minotaur (non-PC) |
