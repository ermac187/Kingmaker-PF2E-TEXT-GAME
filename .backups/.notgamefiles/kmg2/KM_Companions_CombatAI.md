## ACTIVE 11 — PRIORITY SLOT AI
> **DM:** These blocks replace the one-liner for each active companion. Scan slots top to bottom each turn. First TRUE condition fires — stop. S fires once on Round 1 only. Slot 0 fires off-turn on its trigger condition. Adjust thresholds mid-game with `.tactics [name] [slot] [new condition]`.
>
> **Heal thresholds (defaults):** Emergency reaction = ≤ 15% | Priority heal = ≤ 30% | Self-heal = 35–45% | Sucrose elixir = ≤ 25% reaction / ≤ 35% active
