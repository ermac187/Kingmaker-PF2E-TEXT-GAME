# DCs — the anchor tables

Source: PF2E core rules (Gamemastery / Core rulebook DC-setting rules). These are
seeded because they are the backbone the GM falls back on for any ad-hoc call.
**Verify against your own data and replace if your tables differ.**

## Simple DCs (by proficiency rank)

Use when a task has no level — gate on how trained the character is.

| Proficiency | DC |
|---|---|
| Untrained | 10 |
| Trained | 15 |
| Expert | 20 |
| Master | 30 |
| Legendary | 40 |

## DC adjustments

Apply to a base DC to make a task harder or easier. Stackable with care.

| Difficulty | Adjustment |
|---|---|
| Incredibly easy | −10 |
| Very easy | −5 |
| Easy | −2 |
| Hard | +2 |
| Very hard | +5 |
| Incredibly hard | +10 |

Rarity adjustments (for Recall Knowledge etc.):

| Rarity | Adjustment |
|---|---|
| Uncommon | +2 |
| Rare | +5 |
| Unique | +10 |
